# Informed generation implementation contract

Owner approved 2026-09-12. Implement a usable vertical: fast deterministic scoring, persistent preparation, verified card capabilities, landfall plans and protected packages, bounded diversified candidates, explicit simulation capability checks, a C++ resource-development scenario, final evidence and review. Preserve existing owner authentication, quotas, model spend ledger, Aang protected clone behavior, and Main/QA isolation.

This spec supersedes stale localhost/Anthropic/no-simulation assumptions in legacy CLAUDE.md. Architecture.md records the long-term design. Full multiplayer/combat/field-model calibration and exhaustive rules coverage remain research milestones, not claimed capabilities of this release. Every implemented metric must identify its modeled scope; missing effects cannot become zeros presented as real performance.

Acceptance:
- Pairwise scoring equivalent to the reference across adversarial clauses, malformed metadata and a public-card sample, with >=90% reduction measured on rule matching.
- Persistent embeddings invalidated by text and model revision; no encoder on empty reference corpus; corruption/missing cache must not fabricate results.
- Accepted swaps strictly improve CURRENT objective. Every terminal replacement passes semantic/card/budget checks; no unreviewed second replacement chain.
- Typed facts distinguish prerequisites, faces, reliable effects and unknowns; landfall plan protects enablers/payoffs, budgets feasible roles, reports unfulfilled requirements.
- Candidate exploration bounded and deterministic, valid 99+commander, price/singleton/color checks per candidate; unaffected protection/interaction floors retained.
- Simulation adapter has versioned input/output, deck identity, capability checks, timeout/resource bounds, no fabricated fallback. C++ scenario validates only declared mana/resource flow; unsupported mechanics explicitly reported and cannot drive affected comparisons.
- Final result records plan, capability findings, candidate comparison rationale, simulation limitations, timings and decision evidence; legacy decks still render.
- Public/synthetic unit/integration tests; isolated public-catalog Aesi/Aang acceptance; native C++ ASAN tests and release benchmark. Existing full generator suite and container/wheel smoke pass. No production deployment in this build request.

Ownership: Cursor handles isolated performance/cache/presentation tasks; coordinator handles semantics, selection, simulator model, integration and independent acceptance. No production data/credentials to agents. Source and public synthetic fixtures only.

See [operator setup and rollback](operations.md) and [validation, measured
performance, and remaining limitations](validation.md). Prepared facts currently
use `card-facts.v2`; a parser update invalidates prior snapshots.
